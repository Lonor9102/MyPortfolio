# THREADS — демонстрационный интернет-магазин

THREADS — портфолио-проект демонстрационного интернет-магазина одежды. Проект создан для демонстрации навыков адаптивной вёрстки и клиентской логики на HTML, CSS и JavaScript.

## Возможности

- Каталог товаров с динамическим отображением карточек.
- Поиск товаров по названию.
- Фильтрация по категориям.
- Сортировка по цене.
- Сброс параметров каталога.
- Корзина: добавление товаров, изменение количества и удаление позиций.
- Подсчёт общей стоимости заказа.
- Сохранение корзины в `localStorage`.
- Демонстрационное оформление заказа без реальной оплаты.
- Уведомления о добавлении товара и оформлении заказа.
- Светлая и тёмная темы с ручным переключением.
- Автоматический выбор начальной темы по настройкам устройства, если пользователь ещё не сделал собственный выбор.
- Адаптивная вёрстка для мобильных устройств и компьютеров.
- Поддержка клавиатурного фокуса и системной настройки уменьшения анимации.

## Технологии

- **HTML5** — структура страниц и семантическая разметка. 
- **CSS3** — стилизация, Flexbox, Grid, адаптивность, состояния элементов и темы оформления.
- **JavaScript** — работа с DOM, обработчики событий, каталог, корзина и взаимодействия.
- **LocalStorage** — сохранение корзины и предпочтения темы в браузере.

## Запуск проекта

1. Скачайте или склонируйте папку проекта.
2. Откройте `index.html` в браузере.

Для удобной разработки можно открыть папку проекта в Visual Studio Code и использовать расширение Live Server.

## Важные ограничения

THREADS — демонстрационный фронтенд-проект, а не действующий интернет-магазин.

- Данные каталога хранятся в JavaScript.
- Корзина сохраняется локально в браузере пользователя.
- Серверная часть, база данных, авторизация и обработка заказов не реализованы.
- Кнопка оформления заказа демонстрирует пользовательский сценарий; платёж не выполняется и заказ не отправляется в магазин.

## Цель проекта

Продемонстрировать навыки создания адаптивного интерфейса, построения интерактивной логики на JavaScript, работы с состоянием интерфейса и хранения пользовательских настроек в браузере.
