    if (entry.isIntersecting) {
      entry.target.classList.add("reveal", "active");

3. Разбираем новую технологию
Здесь у нас появился интересный инструмент — IntersectionObserver.

Он следит за тем, попадает ли элемент в видимую область экрана.

Например:

if (entry.isIntersecting) {
  entry.target.classList.add("reveal", "active");
}

Переводим:

entry.isIntersecting — элемент появился в области просмотра.

entry.target — сам элемент.

classList.add() — добавляем ему CSS-классы.

А threshold: 0.15 означает, что примерно 15% элемента должны попасть в область просмотра, чтобы сработало наблюдение.
