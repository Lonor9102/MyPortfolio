NOVA Studio

NOVA Studio — демонстрационный portfolio-проект, представляющий навыки frontend-разработки на примере современного сайта креативной digital-студии.

О проекте

Проект демонстрирует умение создавать современные, адаптивные и интерактивные веб-интерфейсы с использованием HTML, CSS и JavaScript.

Основной акцент сделан на визуальной подаче, удобстве взаимодействия, адаптивности и доступности интерфейса.

Технологии

HTML5

CSS3

JavaScript (Vanilla JS)

Реализованные возможности

Адаптивная верстка для мобильных устройств и десктопов.

Мобильная навигация с интерактивным меню.

Анимация появления элементов при прокрутке страницы.

Интерактивные карточки проектов.

Модальное окно с динамическим содержимым.

Управление модальным окном с помощью клавиатуры.

Поддержка клавиатурной навигации и видимого фокуса.

Копирование электронной почты в буфер обмена.

Поддержка системной настройки уменьшения анимации (prefers-reduced-motion).

Структура проекта

index.html — структура страницы.

style.css — стилизация, адаптивность и анимации.

script.js — интерактивность и обработка событий.

Цель проекта

Продемонстрировать практические навыки frontend-разработки, умение работать с DOM, создавать адаптивные интерфейсы и реализовывать интерактивные функции без использования сторонних JavaScript-библиотек.

Проект создан в демонстрационных целях и не является коммерческим сайтом реальной компании.
